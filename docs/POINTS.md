# 养成计划积分

每个群有独立账本。后台“养成计划”提供排行榜、积分调整、流水、账户身份核对、历史导入和折叠的积分设置。每次增减必须填写原因；账户版本防止旧页面覆盖新修改，请求编号防止重试重复入账。

群内默认口令由 `points_policies.config.commands` 管理：`签到` / `签到加积分`、`积分` / `我的积分` / `我的排名`、`积分排行` / `积分排行榜`、`积分红包` / `发积分红包`。后台可修改或清空任意一组。初次配置从 `assets/points_policy.v1.json` 读取；保存后的数据库配置优先，清空不会恢复默认词。新群默认关闭，需管理员启用。

新增可配置的 `add`、`subtract`、`lookup` 三组口令；旧设置读取时补空列表，不自动植入口令，不覆盖已保存配置。柴宝群通过管理 API 配置为 `添加积分`、`减少积分`、`查积分`。管理员回复群友消息发送 `添加积分 100` 或 `减少积分 100`，也支持不加空格的 `添加积分100`、`减少积分100`。后台只填写口令，不需要为不同数字或空格另加词条；自定义加分、扣分口令同样支持。数字必须为正整数，扣分不能超出余额。完整口令优先，其次使用最长口令拆分数字；排队期间修改口令导致金额改变时取消旧操作。执行时查询 Telegram 当前管理员身份；操作记入现有积分流水，记录管理员、目标账户和消息编号，同一消息重放不会重复记账。

所有群友都可用 `查积分`：不回复时查自己，回复群友消息时查对方。原有 `积分` / `我的积分` / `我的排名` 仍查询自己。查询不会给没有账户的人新建账户，机器人、频道及匿名身份不支持回复操作。

默认每天签到一次，加 10 分；北京时间零点换日。至少 3 个汉字的普通聊天每条 1 分，两次加分至少相隔 60 秒，每天最多 50 分。转发、已拦截消息和相邻重复内容不加分；消息先经过群管理，等待已排队的广告核查后才入账。编辑不额外加分。没有签到补签、复杂任务、等级或商店。

`积分红包 100 5` 发出 100 分、5 份拼手气红包；回复某位成员发送 `积分红包 100` 是该成员专属红包。全部使用整数积分，每份至少 1 分、最多 100 份。发送时扣除，领取按数字 ID 去重，并核实仍在群内；默认 24 小时过期，后台定期退还余额。进程重启后仍会结算，停服时在恢复服务后退款。Telegram 发送结果不明时复用现有发送回执机制，不冒险重发；未领取积分仍会到期退款。

历史导入为 JSON，字段为 `batch_key`、`source`、`rows`。每行包括 `source_key`、`display_name`、`points`，可提供已核实的 `user_id`、`source_rank`、`note`。同批同内容重放无副作用；同批不同内容、重复来源或重复数字 ID 会整批拒绝。同名不自动合并，导入不会覆盖既有余额。数据文件与迁移代码分开保存，不在数据库迁移里植入成员名单。
