# 群抽奖

管理员私聊 `/admin` → 选群 → **抽奖管理**，或在网页后台打开“抽奖管理”。支持免费报名、积分报名和消耗积分即时抽奖；积分门槛与近期活跃条件可以自由组合，不提供指定名单抽奖。免费活动无需启用积分；使用积分、积分奖品或活跃条件时，先开启本群积分功能。

## 建立和发布

新建活动先保存为草稿。填写标题、说明和奖品，按需设置每次消耗积分、参与前积分余额门槛，以及最近多少天内至少多少天获得聊天积分。门槛按参与前余额检查，本身不扣分；签到、红包和管理员加分不算聊天活跃，统计含北京时间当天。发布前可编辑，发布后规则固定。暂停群保护不暂停独立的抽奖活动。

报名抽奖每人一次机会、最多中奖一次，所有报名者机会相同。支持管理员手动开奖、北京时间定时开奖、报名达到指定人数自动开奖；每场最多 20 个中奖名额，可分不同奖品。参与人数少于中奖名额时按奖品列表顺序发放；最低成团人数可单独设置，不足时自动取消并退回报名积分。正常开奖后未中奖不退报名积分，活动取消时退款。

即时抽奖须消耗积分，点击参与后立即得到结果；可设置每人每天次数，按北京时间零点重置。每项奖品填写数量和概率权重，可添加“未中奖”。概率为该项权重除以总权重；每次独立随机。某项奖品领完后，抽到该项算未中奖，其余概率不变；所有实际奖品领完后停止扣分。支持手动结束或定时结束，已完成抽奖不退回积分。

积分奖品由机器人记入本群积分流水；会员、实物、兑换码等人工奖品保留中奖者与待发放记录，管理员实际交付后点击“登记已发放”。不接入支付或自动配送。余额达到积分上限时，退款或奖励保留为待处理，余额降低后后台自动补发，不丢账。

## 群友参与

发布会向本群发送完整规则和参与按钮。群友也可在群里发送 `/lottery`，从进行中的活动中查看规则，再点击免费报名或消耗积分参与。费用、门槛、奖品、概率和开奖条件均在参与前显示。只有仍在本群的个人账号可以参与；报名按 Telegram 数字 ID 去重，即时抽奖的同一次请求重放不会重复扣分。活动按钮中的“我的参与 / 中奖记录”显示本人最近三条记录。

定时活动每 30 秒检查一次，短暂延迟属于正常情况。报名、结果、积分流水和待发放记录都保存在数据库，重启后继续处理；停服期间到期的活动恢复后结算。公告使用现有可靠发送任务，发送结果不明时不自动重发；活动详情可查最近的发送结果，管理员核实群内后可主动重发公告或结果。

## 复用往期抽奖

活动列表和详情均有 **复用配置**。草稿、已开奖、已结束或已取消的活动都可复制为独立新草稿，保留标题、说明、奖品、积分与活跃门槛、开奖方式、每日次数等配置。新活动不继承参与名单、积分扣款、中奖结果、领取状态或库存消耗。定时活动保留定时方式，但清空旧时间；必须重新设置未来时间才能发布。复制不会修改原活动。

## 管理接口与升级

沿用现有后台登录与群管理员权限。`GET /api/groups/{group_id}/lotteries` 列表分页；`GET /api/groups/{group_id}/lotteries/{id}` 查看活动、库存、参与记录和发送情况，支持 `page_number` 与 `entry_state` 筛选。`POST` 列表地址创建草稿，`PUT` 活动地址修改草稿，正文为 `config` 和 `version`；`POST .../{id}/operate` 接受 `publish`、`draw`、`cancel`、`close`、`announce`、`fulfill`、`copy` 操作，并携带当前 `version`，领奖登记另传 `entry_id`。写入使用 `Idempotency-Key`；相同请求重放返回原结果，不同内容复用同一请求编号会拒绝。

0037 迁移新增活动和参与记录表，不改原有积分余额、词库或群设置。已有实例在按原升级流程停服后执行数据库迁移，再启动新版；本次开发验证不代表已更新服务器或真实群。
