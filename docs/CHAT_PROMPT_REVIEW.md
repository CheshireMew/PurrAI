# 聊天提示词

## 本轮版本（2026-10-29）

名字自动使用 Telegram getMe 返回的显示名，未取得身份时退回群设置中的昵称；性格使用群设置。

取消 direct/followup/ambient 和 reply_audience 分类，移除按 90 秒推断交谈对象的规则。模型在同一次请求中先决定 should_reply，再生成文字或贴纸。直接问到但不知道时可以如实说明，没被问到时不以“不知道”插话。

请求提供 bot_id、bot_username、按时间排列的 messages 和目标消息 reply_to。每条消息列明 id、speaker_id、name、bot、text、time，引用关系使用 reply_to、reply_to_speaker_id、reply_to_name；引用正文已在列表中时不重复附带。群开关、广告与命令过滤、请求间隔和预算仍由程序执行，不再代表对人际关系的判断。

此前本地聊天相关回归 350 项通过，最终请求结构另复核 3 项通过；Ruff 和差异空白检查通过。以上使用模拟模型与 Telegram，不代表真实模型效果验证；合并验证与实际发布状态见 [验证记录](../VALIDATION.md)。

## 当前程序过滤（2026-10-23）

移除调用模型前固定的 10 秒等待和聊天层额外的 8 秒回复间隔；符合条件的消息立即进入处理，模型生成和已有接口限流仍需时间。已排队的同组补充仍可合并，不为了合并另加等待。已经判违规、安排删除或记录为已删除的原文，会从新上下文和旧缓存中一起排除；相应引用与机器人此前针对它的回复也一并排除。生成期间若相关上下文失效，取消尚未发送的文字和贴纸，不额外请求一次模型。

功能口令按整条消息匹配，忽略空白和英文大小写，默认是“签到、积分、抽奖、注册币安、注册 OKX、币圈教程”。每个群可通过 Telegram 聊天设置或网页群设置修改，清空可关闭过滤。这份名单不发送给 AI，正常句子包含这些词时仍可讨论。没有直接询问机器人的广告议论会跳过，包括无关续聊中的插曲；被点名提问，以及同一用户明确询问广告问题后的正常追问，仍可处理。

机械过滤独立于模型和成员处罚，复用群内启用的正文关键词、禁止域名及账号规则，也识别隐藏链接。另用组合条件识别跑分和灰产招聘、推广业务并要求私聊或看简介、付费频道免费引流话术，以及收益承诺并要求加群或注册；规范化全角、零宽字符、空白干扰。普通提到某个词不直接认定广告，明确询问真假和识别方法仍可处理。按同一成员的连续消息检查拆开的招揽内容；调用模型前、缓存复用及发送前重查最新规则，过滤命中的文字和引用，不据此创建成员违规或处罚。模型必须给出布尔值 is_advertisement，缺失或格式错误不发送；广告标志为 true 时，程序强制丢弃文字和贴纸，即使 should_reply 被错误写成 true。旧版已发文字、但没有有效广告判定的部分发送缓存不再继续发贴纸，也不重新生成正文。

图片不送入纯文字模型。同一用户、同一群及 Telegram 子话题内，相邻消息间隔不超过 10 秒仍视为一组，这个时间只用于关联连续消息，不是回复延迟。普通含图消息组、单独图片和未叫机器人的图片引用不主动回复；被 @、叫昵称或回复机器人时仍可处理，带入不可读图片标记及有效文字，要求模型说明图片不可见。生成期间补图不再取消明确提问的答案，普通插话仍受图片过滤。其他成员或其他子话题的图片不影响正常聊天。

频道帖子仍不主动触发聊天。用户明确叫机器人并引用频道帖子或图片时，取已收到的正文或图片说明作为引用文字；归档中更新过的文字优先，未开启归档时也可使用本次引用附带的文字。不会读取图片、下载文件或增加模型调用；已删除、违规的引用及其他机器人的系统图片仍不带入模型，复用现有字段而不新增数据库迁移。

本机器人删帖成功，或 Telegram 明确返回原消息不存在时，自动为关联的已发文字和贴纸安排持久撤回任务；待发内容取消。发送编号及直接引用来源复用已有字段保存，保留 Telegram 允许删除的 48 小时及两分钟生成余量，关闭归档或重启后仍可继续清理，失败不会冒充成功。普通群的 Bot API 不提供用户及其他机器人删帖通知；没有得到确切删除事实时，不能保证立即感知和同步撤回。文字和贴纸仍要求被回复的原消息存在，不用额外发消息或尝试修改他人消息来探测删除。整体复核及边界见 [聊天系统复核](CHAT_SYSTEM_REVIEW.md)。
